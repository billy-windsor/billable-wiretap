Create a proportional Venn diagram using two or three sets. Enter the size of each set and the overlap between every pair. The circles are positioned and scaled automatically.

Set names and sizes

Pairwise overlaps

Enter the number of items shared by each pair of sets.

Pairwise overlap values include anything that may also appear in all three sets. The central three-way intersection is produced by the geometry of the three pairwise relationships.
